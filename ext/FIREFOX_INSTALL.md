# Установка расширения в Firefox

1. Открыть `about:debugging#/runtime/this-firefox` в адресной строке.
2. Нажать **«Load Temporary Add-on…»**.
3. Выбрать файл `ext/.output/firefox-mv2/manifest.json`.
4. Расширение появится в списке и в панели инструментов.

Готово. Зайти на сайт Otclick и авторизоваться — расширение подхватит сессию само.

## Важно

- Это **временная** установка: расширение пропадёт при перезапуске Firefox,
  нужно будет повторить шаги 1–3 заново.
- Если папки `.output/firefox-mv2` нет или она устарела — собрать заново:
  ```
  cd ext && npm install && npm run build
  ```
- Постоянная установка возможна только через `.xpi`, подписанный Mozilla
  (`npm run zip` → загрузить zip на https://addons.mozilla.org).
